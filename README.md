# Manufacturing Cost Analytics

Methods from my Cost Controlling internship (Finance) at an OEM/ODM houseware manufacturer in Dongguan, China.

> All examples in this repo use **synthetic data**. No company file, figure or customer information is published: the original data stays under NDA.

## Topics

| Topic | What it shows |
|---|---|
| **BOM update automation** | Python scripts that update bills of materials in legacy Excel files without breaking merged cells |
| **Purchasing price trends** | Price evolution by material family (silicone, plastics, outsourced parts, packaging) |
| **Standard costing** | A standard cost model for a product line, from materials and labor to unit cost |
| **Tooling analytics** | A dashboard of mold interventions by cause (sampling, R&D changes, production repairs) |

## Stack

`Python` `openpyxl` `Pandas` `Excel` `React` `Recharts`
